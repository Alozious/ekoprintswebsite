# Assets Directory

Please place the following files in this directory:

1. **logo.png**: The main logo image for the website (Header and Footer).
   - You can download your logo from: https://drive.google.com/uc?id=1PpzbvTQjgVf4YTreFUhpNef5vTFAU4SW
   - Rename it to `logo.png` and place it here.

2. **favicon.ico**: The favicon for the browser tab.
   - Place your generated favicon here.

The website is configured to look for these files at `assets/logo.png` and `assets/favicon.ico`.
